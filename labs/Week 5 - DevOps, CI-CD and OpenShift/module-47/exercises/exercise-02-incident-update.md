# Exercise 2 — Draft Incident Update Skeleton

**Module 47** · Documentation exercise · [setup](EXERCISES-INDEX.md)

## Goal

Outline an incident update without naming blame.

## Steps

### Step 1 — Sections

Summary, impact, current status, what we know, next update time, contacts.

### Step 2 — Check the reference

No invented root cause; no credentials; no customer PII.

### Step 3 — Impact line

Write one impact sentence mentioning agents and synthetic customer IDs only.

### Step 4 — Next update

Pick a concrete next-update clock time placeholder.

## Expected result

Incident update skeleton with next-update time.
