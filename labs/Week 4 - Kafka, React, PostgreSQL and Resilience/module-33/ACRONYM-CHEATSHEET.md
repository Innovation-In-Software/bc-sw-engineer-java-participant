## Frontend

| Term | Full form | Simple meaning |
| --- | --- | --- |
| **DOM** | Document Object Model | Browser’s tree of HTML elements. |
| **JSX** | JavaScript XML | Syntax that looks like HTML inside JavaScript/React. |
| **Node.js** | — | JavaScript runtime used for tooling and some backends. |
| **npm** | Node Package Manager | Installs and runs JavaScript packages. |
| **Props** | Properties | Inputs passed from parent to child React components. |
| **React** | — | Library for building UI from components. |
| **SPA** | Single-Page Application | Web app that updates in the browser without full page reloads. |
