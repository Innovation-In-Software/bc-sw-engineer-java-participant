# Exercise 4 — Component Inventory

**Module 33** · Analysis exercise · [setup](EXERCISES-INDEX.md)

## Goal

List CRM dashboard components you will build in Lab 33.

## Steps

### Step 1 — Screen

Imagine a Customer list showing Amina and Ravi with status badges.

### Step 2 — Inventory

List ≥5 components: e.g. `App`, `CustomerList`, `CustomerCard`, `StatusBadge`, `PageHeader`.

### Step 3 — One responsibility

For each, write a ≤6-word responsibility.

### Step 4 — Notes

Save as `notes/lab33-components.md`.

## Expected result

A component inventory with single-responsibility blurbs.
